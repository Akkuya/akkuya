## things i've built

### [FinTrack](https://github.com/Akkuya/finTrack)
`Python` `FastAPI` `React` `TypeScript` `SQLite` `Ollama`

A local-first personal finance app for tracking transactions, spending, and savings goals.

- Imports and processes transaction CSVs from Simplii and Tangerine.
- Combines rule-based transaction categorization with local LLM assistance through Ollama.
- Uses a FastAPI backend, SQLite database, and React frontend.

### Multiplayer Battleship Server
`C` `POSIX Sockets` `TCP/IP`

An event-driven multiplayer Battleship server written in C, supporting up to 64 concurrent players.

- Uses `select()` and non-blocking sockets to manage connections in a single process.
- Implements per-client buffering, message validation, and disconnect handling.
- Manages game sessions and broadcasts game-state updates between players.

### Multisports Timer
`Python` `PySide6` `PyInstaller`

A Windows desktop utility I built and deployed at Aerosports Parks, used by 10+ staff members to coordinate simulator sessions.

- Implements a session state machine with configurable global hotkeys.
- Includes audio alerts, persistent event logging, and customizable settings.
- Packaged as a standalone Windows application.

*Internal project — source not publicly available.*

### [Android Artifact Management App](https://github.com/Akkuya/B07Project)
`Java` `Android` `Firebase`

An Android application for browsing and managing artifacts backed by Firebase.

- Implements local searching, filtering, sorting, and pagination.
- Uses Firebase Authentication and Realtime Database for user and artifact data.
- Handles image loading, user sessions, and account deletion.
